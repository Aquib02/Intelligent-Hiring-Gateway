# Intelligent Hiring Gateway - AI-Powered Recruitment Platform

An advanced, 3-tier full-stack AI recruitment platform built to streamline the hiring process through automated resume parsing, ATS match-scoring, and intelligent candidate ranking using the Google Gemini API.

## Features

* **Automated Resume Parsing & ATS Scoring:** Extracts text from uploaded PDF resumes and evaluates candidates against job descriptions to reduce manual screening effort.
* **Google Gemini API Integration:** Leverages generative AI for intelligent skill matching, candidate ranking, and match-score generation.
* **Recruiter & Candidate Dashboard:** Comprehensive dashboard for managing job postings, reviewing applicant matches, and tracking recruitment pipelines.
* **Robust Backend API:** Built with FastAPI to ensure high-performance asynchronous request handling and seamless frontend-backend communication.

## Tech Stack

* **Frontend:** React.js, Tailwind CSS, JavaScript
* **Backend:** Python, FastAPI, REST APIs
* **Database:** SQLite
* **AI & Parsing:** Google Gemini API, PyPDF / PDF parsing libraries

## Getting Started

### Prerequisites
* Python (v3.8+) installed
* Node.js and npm installed
